# Artwork in the public v0.2.0 packages

The Alter logo, wordmark, and app icon were supplied for this project. They are separate from the MIT license that covers the source code.

The public Windows and source archives omit the previously supplied Batman and Phantom Blade Zero images because redistribution rights have not been established. Home and Community use built-in dark purple banner treatments when those files are absent.

Users may add their own locally licensed `assets/hero.jpg` and `assets/community-hero.jpg`. Alter will display them without uploading them. Artwork embedded in a user's trainer profile also stays local unless that user exports and shares the profile.
