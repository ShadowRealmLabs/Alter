ALTER v0.2.0

Extract this ZIP to a writable folder and run Alter.exe. Keep the assets folder beside it. Your Library starts empty. Use Library to create or import a trainer.

Alter is an early local Windows trainer creator. It can scan and edit numeric game values, run user-authored features after a trust prompt, import simple Cheat Engine entries, and organize external FLiNG trainer hotkeys. An imported FLiNG EXE is still needed to execute its cheats. No game-specific trainer is bundled or verified.

Settings checks GitHub Releases for a version newer than v0.2.0 and offers a link to its release page. See README.md and RELEASE_NOTES.md for features, limits, build instructions and licensing. The public package omits third-party game artwork.
